============================================================
 VidPlayer 少女心本地视频播放器 —— 使用说明 & APK 打包全流程
============================================================

一、软件功能（本次已全部实现并测试通过）
------------------------------------------------------------
1. 手动选择手机上的视频文件夹，进入后像“文件管理器”一样浏览
   子文件夹和视频，点视频即播放；可随时返回上级、更换文件夹。
2. 倍速：1x / 1.5x / 2x / 3x / 5x，五档全部【带声音】，
   声音保音调加速（不会变成怪声），音画同步；拖动进度条可快进/后退。
   （实现方式：FFmpeg atempo 音频滤镜，切换倍速时有约 0.1~0.3 秒
   重开缓冲，属于正常现象；没有音轨的视频则静音快速跳帧。）
3. 自定义封面（核心功能）：播放时先暂停，点“暂停并设为封面”，
   当前画面即成为该视频在列表里的封面，永久有效。
   · 程序会在你选择的视频文件夹里自动创建并维护 VidPic 文件夹；
   · VidPic 的目录结构与视频文件夹完全一致；
   · 视频  某文件夹/a.mp4  →  封面  VidPic/某文件夹/a.mp4.png；
   · 下次打开软件自动从 VidPic 读取封面，没设置过的用默认粉色封面。
4. 界面为可爱少女动漫风：樱粉配色、圆角卡片、爱心元素、
   ZCOOL 快乐体中文字体（已随包打包，不会出现方块乱码）。
5. 自动记住上次选择的文件夹；安卓返回键可逐级返回。


二、关于“能不能直接用 Python 库在 Windows 上打包 APK？”
------------------------------------------------------------
Python 打包安卓 APK 的标准工具链是 buildozer + python-for-android，
它本质上要在 Linux 里调用 Android SDK/NDK 编译 FFmpeg、SDL2 等
原生组件，【不能在 Windows 原生环境直接运行】，也没有“pip 装一个
库就出 APK”的办法。可行路线只有两条：

  路线 A（推荐，免费、不用装环境）：GitHub Actions 云端 Ubuntu 打包
           —— 把代码传到 GitHub，云端自动编译，下载 APK。详见第三节。
  路线 B（本机打包）：Windows 装 WSL(Ubuntu)，在 Linux 里编译。
           —— 双击「打包辅助\一键打包APK.bat」即可，详见第五节。


三、GitHub Actions 云端打包：一步一步操作（路线 A）
------------------------------------------------------------
准备：注册一个 GitHub 账号并登录（github.com，可用浏览器/手机）。

第 1 步：新建仓库
  1) 右上角 + → New repository；
  2) Repository name 随便填，例如 vidplayer；
  3) 选 Public（公开，免费额度可直接用；Private 也可以，但免费
     账号 Actions 分钟数有限制）；
  4) 不要勾选 Add README/.gitignore/license，直接点 Create repository。

第 2 步：上传本文件夹里的文件（结构必须保持不变）
  在空仓库页面点 “uploading an existing file”，把本项目文件夹里
  以下内容整体拖进去（可以全选后一次拖入）：
     .github\            （隐藏文件夹，里面是自动打包脚本，必须传！）
     assets\             （应用图标、启动画面）
     fonts\              （中文字体）
     main.py
     vidcore.py
     vidutil.py
     buildozer.spec
     requirements.txt
  可选上传：打包辅助\、本说明 txt。
  【不要上传】bin、.buildozer、APK输出、__pycache__（本机构建缓存，
     传了反而可能出错；本项目已带 .gitignore，用 git 命令时会自动忽略）。
  注意：main.py、buildozer.spec、.github 必须在仓库【最外层根目录】，
     不要再套一层文件夹。
  拖完后页面下方 Commit changes → 直接点 Commit changes。

第 3 步：查看自动构建
  1) 点仓库顶部的 Actions 标签页；
  2) 提交代码后会自动出现一条名为 Build-VidPlayer-APK 的运行记录，
     点进去再点 build 可看到 9 个步骤依次打勾：
       检出代码 → 设置 Python → 缓存 → 安装系统依赖 → 代码语法自检
       → 安装 buildozer 与 Cython → 打包 APK → 上传 APK 产物；
  3) 首次打包要下载 SDK/NDK 并编译 FFmpeg，约 30~90 分钟，
     页面挂着即可，关掉手机/电脑也没关系，云端会继续跑。
  也可以在 Actions 页面手动点 Run workflow 重新构建。

第 4 步：下载 APK
  全部步骤变绿（成功）后，点进该次运行，拉到页面最下方 Artifacts，
  下载 “VidPlayer-debug-apk”（是一个 zip，解压后得到 .apk 文件）。

第 5 步：装到手机
  把 apk 发到手机（QQ/微信/数据线/网盘均可），点击安装；
  首次安装会提示“允许安装未知来源应用”，允许即可。


四、手机上的使用流程与授权
------------------------------------------------------------
1. 打开 VidPlayer，点“选择视频文件夹”，在系统文件选择器里点选
   存放视频的文件夹后点“选择此文件夹”（可以先点顶部快捷路径跳转）。
2. 安卓 11 及以上：第一次使用请按弹窗提示授予“允许管理所有文件”
   权限（否则无法在视频文件夹里创建 VidPic、保存封面）。
3. 列表中点文件夹进入、点视频播放；播放页可暂停/播放、拖进度条、
   切倍速；想设封面就先暂停，再点“暂停并设为封面”，提示保存成功即可。
4. 下次进入可直接点“进入上次选择的文件夹”。


五、本机 WSL 打包（路线 B，可选）
------------------------------------------------------------
1) 双击运行  打包辅助\一键打包APK.bat ，弹出 UAC 点“是”；
2) 脚本会自动安装 WSL+Ubuntu（若系统提示需要重启，重启后再双击一次）；
3) 之后自动安装依赖并执行 buildozer 编译，首次 30~90 分钟；
4) 成功后 APK 出现在项目目录的「APK输出」文件夹。
   （实际执行的 Linux 脚本是 打包辅助\wsl_build.sh，可重复运行，
    第二次有缓存会快很多。）


六、项目文件结构说明
------------------------------------------------------------
  main.py                 界面与交互（三屏：首页/文件浏览/播放页）
  vidcore.py              播放器内核：ffpyplayer 取帧线程、倍速声音、
                          音画同步、进度、封面截取
  vidutil.py              工具：VidPic 镜像、目录浏览、默认封面/主题
                          素材生成、安卓权限、配置读写
  buildozer.spec          APK 打包配置（包名、权限、架构、依赖配方版本）
  requirements.txt        电脑上调试运行所需依赖（与 APK 内依赖无关）
  fonts\ZCOOLKuaiLe-Regular.ttf   可爱中文字体（OFL 开源授权）
  assets\icon.png         APP 图标
  assets\presplash.png    启动画面
  .github\workflows\main.yml      GitHub Actions 自动打包脚本
  打包辅助\               本机 WSL 一键打包脚本（可选路线）
  bin\ .buildozer\        打包产物/缓存（自动生成，不用管）


七、电脑上调试运行（开发者可选）
------------------------------------------------------------
  需 Python 3.9~3.11：
    python -m pip install -r requirements.txt
    python main.py
  国内网络装 kivy 若失败，可指定官方源：
    python -m pip install kivy ffpyplayer pillow -i https://pypi.org/simple


八、常见问题
------------------------------------------------------------
Q: Actions 某一步红叉失败怎么办？
A: 点进失败步骤看红色日志，把【失败步骤名 + 日志最后 30 行】截图；
   常见原因：①网络抖动（直接 Actions → Run workflow 重跑一次）；
   ②“安装 buildozer 与 Cython”失败——新版工作流已改用独立虚拟
   环境并自动重试，重新拉取本目录最新代码再传一次即可。
Q: 为什么打两个架构（arm64-v8a + armeabi-v7a）？
A: 覆盖新旧手机；若想大幅缩短云端编译时间，可在 buildozer.spec 把
   android.archs 改成只留 arm64-v8a（近 5 年的手机都是这个架构）。
Q: 手机上封面没保存上？
A: 检查是否授予了“所有文件访问”权限；VidPic 必须建在你选择的
   那个视频文件夹内，请勿手动改名或移动。
Q: 切倍速时画面顿一下？
A: 带声倍速需要用 atempo 滤镜重开解码器，约 0.1~0.3 秒，正常现象。
